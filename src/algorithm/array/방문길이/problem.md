# 방문 길이

- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/49994

## 문제 설명

게임 캐릭터를 4가지 명령어를 통해 움직이려 한다. 명령어는 다음과 같다.

- `U`: 위쪽으로 한 칸 가기
- `D`: 아래쪽으로 한 칸 가기
- `R`: 오른쪽으로 한 칸 가기
- `L`: 왼쪽으로 한 칸 가기

캐릭터는 좌표평면의 `(0, 0)` 위치에서 시작한다. 좌표평면의 경계는 왼쪽 위 `(-5, 5)`, 왼쪽 아래 `(-5, -5)`, 오른쪽 위 `(5, 5)`, 오른쪽 아래 `(5, -5)`로 이루어져 있다.

예를 들어 `"ULURRDLLU"`로 명령했다면, 캐릭터는 순서대로 다음 좌표를 지나가게 된다.

```
(0,0) -U-> (0,1) -L-> (-1,1) -U-> (-1,2) -R-> (0,2) -R-> (1,2) -D-> (1,1) -L-> (0,1) -L-> (-1,1) -U-> (-1,2)
```

이때 게임 캐릭터가 지나간 길 중 **캐릭터가 처음 걸어본 길의 길이**를 구하려고 한다. 위 예시에서 게임 캐릭터가 움직인 길이는 9이지만, 캐릭터가 처음 걸어본 길의 길이는 7이 된다. (8, 9번 명령어에서 움직인 길은 2, 3번 명령어에서 이미 거쳐 간 길이다.)

단, 좌표평면의 경계를 넘어가는 명령어는 무시한다.

예를 들어 `"LULLLLLLU"`로 명령했다면, 1번 명령어부터 6번 명령어대로 움직인 후 7, 8번 명령어는 경계를 벗어나므로 무시하고, 다시 9번 명령어대로 움직인다. 이때 캐릭터가 처음 걸어본 길의 길이는 7이 된다.

명령어가 매개변수 `dirs`로 주어질 때, 게임 캐릭터가 처음 걸어본 길의 길이를 구하여 return 하는 `solution` 함수를 완성하라.

## 제한 조건

- `dirs`는 string 형으로 주어지며, `'U'`, `'D'`, `'R'`, `'L'` 이외의 문자는 주어지지 않는다.
- `dirs`의 길이는 500 이하의 자연수이다.
- 좌표평면의 경계를 넘어가는 명령어는 무시한다.
- 같은 구간이라면 방향과 상관없이(왕복 포함) 한 번만 걸은 것으로 센다.

## 입출력 예

| dirs | answer |
| --- | --- |
| `"ULURRDLLU"` | `7` |
| `"LULLLLLLU"` | `7` |
