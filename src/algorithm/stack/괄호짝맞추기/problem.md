# 괄호 짝 맞추기

## 문제 설명

소괄호 `(` 와 `)` 로만 구성된 문자열 `s`가 주어진다. 괄호의 짝이 올바르게 맞는지 판별하는 `solution` 함수를 구현하라.

괄호의 짝이 올바르다는 것은 다음 조건을 모두 만족한다는 뜻이다.

- 모든 열린 괄호 `(` 는 그에 대응하는 닫힌 괄호 `)` 와 짝을 이루어야 한다.
- 짝을 이루는 두 괄호 중 열린 괄호가 항상 닫힌 괄호보다 먼저 나와야 한다.

## 제한 조건

- `s`는 `'('` 와 `')'` 로만 구성된 문자열이다.
- `s`의 길이는 1 이상 10,000 이하이다.

## 입출력 예

| s | answer |
| --- | --- |
| `"()"` | `true` |
| `"(())()"` | `true` |
| `")("` | `false` |
| `"(()"` | `false` |

## 입출력 예 설명

### 입출력 예 #1

여는 괄호와 닫는 괄호가 하나씩 순서대로 짝을 이루므로 `true`.

### 입출력 예 #2

중첩된 괄호 `(())` 와 이어지는 `()` 가 각각 올바르게 짝을 이루므로 `true`.

### 입출력 예 #3

닫힌 괄호가 열린 괄호보다 먼저 나오므로 `false`.

### 입출력 예 #4

여는 괄호 하나가 짝을 이루지 못하고 남으므로 `false`.
