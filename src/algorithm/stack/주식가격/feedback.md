# 피드백

## 잘한 점

- 모노토닉 스택 패턴을 정확히 적용했다. 각 원소가 스택에 최대 한 번 push, 한 번 pop 되므로 전체 O(N) — 요구되는 시간복잡도를 만족한다.
- `>` (등호 없이) 로 비교한 것이 정확하다. 문제 정의상 "떨어지지 않음"은 이전 값보다 크거나 같을 때도 포함되므로, 같은 값에서 잘못 종료되지 않는다.
- `if len(stack) == 0` 분기를 `while len(stack) > 0 and ...` 조건 안으로 합쳐서 IndexError를 유발하던 초기 버전보다 깔끔해졌다.

## 아쉬운 점 (사소함)

- `stack`에 `(i, price)` 튜플 대신 인덱스만 저장해도 된다. `prices[stack[-1]]`로 가격을 바로 조회할 수 있으므로 `past_price` 변수 자체가 필요 없어진다. 틀린 것은 아니고 취향 차이.
