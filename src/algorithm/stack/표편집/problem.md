# 표 편집

## 문제 설명

행이 `n`개인 표에서 처음 선택된 행이 `k`일 때, 명령어 배열 `cmd`를 모두 수행한 뒤 각 행의 삭제 여부를 문자열로 반환하는 `solution` 함수를 구현하라. 삭제되지 않은 행은 `O`, 삭제된 행은 `X`로 표시하고, 0행부터 `n - 1`행까지 이어 붙인다.

명령어는 다음과 같다.

- `U X`: 현재 행에서 살아있는 행 기준 `X`칸 위를 선택한다.
- `D X`: 현재 행에서 살아있는 행 기준 `X`칸 아래를 선택한다.
- `C`: 현재 행을 삭제한 뒤 바로 아래 행을 선택한다. 삭제한 행이 마지막 행이면 바로 위 행을 선택한다.
- `Z`: 가장 최근에 삭제한 행을 복구한다. 현재 선택된 행은 바꾸지 않는다.

한 번에 한 행만 선택할 수 있고, 표 범위를 벗어나는 이동은 주어지지 않는다. 삭제된 행이 없을 때 `Z`가 나오는 경우와, 모든 행을 지워 표가 비는 경우도 주어지지 않는다.

## 제한 조건

- `n`은 5 이상 1,000,000 이하이다.
- `k`는 0 이상 `n` 미만이다.
- `cmd`의 길이는 1 이상 200,000 이하이다.
- `cmd`의 각 원소는 `"U X"`, `"D X"`, `"C"`, `"Z"` 중 하나이다.
- `X`는 1 이상 300,000 이하인 자연수이며, 모든 `X`의 합은 1,000,000 이하이다.

정확성 테스트는 `n`과 `cmd` 길이가 1,000 이하이고, 효율성 테스트는 위 제한을 그대로 쓴다.

## 입출력 예

| n | k | cmd | result |
| --- | --- | --- | --- |
| `8` | `2` | `["D 2","C","U 3","C","D 4","C","U 2","Z","Z"]` | `"OOOOXOOO"` |
| `8` | `2` | `["D 2","C","U 3","C","D 4","C","U 2","Z","Z","U 1","C"]` | `"OOXOXOOO"` |

## 입출력 예 설명

### 입출력 예 #1

문제 본문의 예시와 같다. 마지막에 두 번 복구한 뒤에도 한 행은 삭제된 채 남으므로 `"OOOOXOOO"`.

### 입출력 예 #2

입출력 예 #1과 같은 상태까지 간 뒤 `"U 1"`, `"C"`를 더 수행하면 2행이 추가로 삭제되어 `"OOXOXOOO"`.
