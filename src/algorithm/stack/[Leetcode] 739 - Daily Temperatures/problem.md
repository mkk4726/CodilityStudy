# 739. Daily Temperatures

## 문제 설명

정수 배열 `temperatures`는 일별 기온을 나타낸다. `answer[i]`는 i번째 날 이후 더 따뜻한 날이 오기까지 기다려야 하는 일수이다. 그런 날이 없으면 `answer[i]`는 `0`이다.

`answer` 배열을 반환하는 `solution` 함수를 구현하라.

## 제한 조건

- `1 <= temperatures.length <= 10^5`
- `30 <= temperatures[i] <= 100`

## 입출력 예

| temperatures | result |
| --- | --- |
| `[73, 74, 75, 71, 69, 72, 76, 73]` | `[1, 1, 4, 2, 1, 1, 0, 0]` |
| `[30, 40, 50, 60]` | `[1, 1, 1, 0]` |
| `[30, 60, 90]` | `[1, 1, 0]` |

## 입출력 예 설명

### 입출력 예 #1

- 73 → 다음 날 74가 더 따뜻하므로 `1`
- 74 → 다음 날 75가 더 따뜻하므로 `1`
- 75 → 4일 뒤 76이 더 따뜻하므로 `4`
- 71 → 2일 뒤 72가 더 따뜻하므로 `2`
- 69 → 다음 날 72가 더 따뜻하므로 `1`
- 72 → 다음 날 76이 더 따뜻하므로 `1`
- 76, 73: 이후 더 따뜻한 날이 없으므로 `0`

### 입출력 예 #2

매일 다음 날이 더 따뜻하고, 마지막 날은 이후가 없으므로 `[1, 1, 1, 0]`이다.

### 입출력 예 #3

매일 다음 날이 더 따뜻하고, 마지막 날은 이후가 없으므로 `[1, 1, 0]`이다.
