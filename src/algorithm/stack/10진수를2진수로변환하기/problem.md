# 10진수를 2진수로 변환하기

## 문제 설명

0 이상의 정수 `n`(10진수)이 주어질 때, 이를 2진수로 변환한 문자열을 반환하는 `solution` 함수를 구현하라.

`n`을 2로 나눈 나머지를 스택에 순서대로 쌓은 뒤, 스택에서 꺼낸 순서(나머지가 나온 역순)로 이어 붙이면 2진수 표현을 얻을 수 있다.

## 제한 조건

- `n`은 0 이상 1,000,000 이하의 정수이다.
- 반환값은 앞에 불필요한 0이 없는 2진수 문자열이어야 한다. 단, `n`이 0이면 `"0"`을 반환한다.

## 입출력 예

| n | answer |
| --- | --- |
| `0` | `"0"` |
| `1` | `"1"` |
| `10` | `"1010"` |
| `255` | `"11111111"` |

## 입출력 예 설명

### 입출력 예 #1

`0`은 그대로 `"0"`.

### 입출력 예 #2

`10`을 2로 나눈 나머지를 순서대로 쌓으면 `0, 1, 0, 1`이고, 역순으로 이어 붙이면 `"1010"`.
