# 크레인 인형뽑기 게임

## 문제 설명

`N x N` 격자 `board`와 크레인을 작동시킨 위치 배열 `moves`가 주어진다. 크레인은 `moves`의 각 열에서 가장 위에 있는 인형을 집어 바구니에 쌓는다. 바구니에서 같은 모양의 인형 두 개가 연속으로 쌓이면 두 인형은 터지며 사라진다. 크레인을 모두 작동시킨 뒤 터져서 사라진 인형의 개수를 반환하는 `solution` 함수를 구현하라.

- 격자의 가장 아래 칸부터 인형이 쌓여 있다.
- 인형이 없는 열에서 크레인을 작동하면 아무 일도 일어나지 않는다.
- 바구니는 모든 인형이 들어갈 수 있을 만큼 충분히 크다.
- `board`의 `0`은 빈 칸이고, `1` 이상 `100` 이하의 같은 숫자는 같은 모양의 인형이다.
- `moves`의 값은 1부터 시작하는 열 번호이다.

## 제한 조건

- `board`는 `5 x 5` 이상 `30 x 30` 이하의 2차원 배열이다.
- `board`의 각 칸은 `0` 이상 `100` 이하의 정수이다.
- `moves`의 길이는 1 이상 1,000 이하이다.
- `moves`의 각 원소는 1 이상이며 `board`의 가로 크기 이하인 자연수이다.

## 입출력 예

| board | moves | result |
| --- | --- | --- |
| `[[0,0,0,0,0],[0,0,1,0,3],[0,2,5,0,1],[4,2,4,4,2],[3,5,1,3,1]]` | `[1,5,3,5,1,2,1,4]` | `4` |

## 입출력 예 설명

### 입출력 예 #1

크레인을 `[1, 5, 3, 5, 1, 2, 1, 4]` 위치에서 차례대로 작동하면 바구니에 담는 과정에서 같은 모양 인형이 두 번씩 두 번 터지므로 사라진 인형은 4개이다.
