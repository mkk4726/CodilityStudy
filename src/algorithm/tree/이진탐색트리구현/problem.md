# 이진 탐색 트리 구현

## 문제 설명

첫 번째 인수 `lst`로 이진 탐색 트리를 만들고, 두 번째 인수 `search_lst`의 각 값이 그 트리에 있는지 확인한다. 찾은 결과는 `True` 또는 `False`를 담은 리스트로 반환하는 `solution` 함수를 구현하라.

이진 탐색 트리는 `lst`의 첫 원소를 루트로 두고, 이후 값을 순서대로 삽입한다. 현재 노드보다 작으면 왼쪽, 크면 오른쪽으로 내려간다.

## 제한 조건

- `1 <= lst의 길이 <= 10,000`
- `1 <= search_lst의 길이 <= 100`
- `lst`의 원소는 정수이며 중복되지 않는다.
- `search_lst`의 원소는 정수이다.

## 입출력 예

| lst | search_lst | result |
| --- | --- | --- |
| `[5, 3, 8, 4, 2, 1, 7, 10]` | `[1, 2, 5, 6]` | `[True, True, True, False]` |
| `[1, 3, 5, 7, 9]` | `[2, 4, 6, 8, 10]` | `[False, False, False, False, False]` |

## 입출력 예 설명

### 입출력 예 #1

`lst`로 만든 트리는 다음과 같다.

```
        5
       / \
      3   8
     / \ / \
    2  4 7  10
   /
  1
```

`1`, `2`, `5`는 트리에 있고, `6`은 없다.

### 입출력 예 #2

트리가 오른쪽으로만 자라서 `1-3-5-7-9`가 된다. `search_lst`의 값은 모두 트리에 없다.
