# 트리 순회

## 문제 설명

이진 트리를 표현한 리스트 `nodes`가 주어진다. 예를 들어 `nodes`가 `[1, 2, 3, 4, 5, 6, 7]`이면 다음과 같은 트리를 나타낸다.

```
      1
     / \
    2   3
   / \ / \
  4  5 6  7
```

`nodes`는 레벨 순서(완전 이진 트리) 배열이다. 인덱스 `i`의 왼쪽 자식은 `2 * i + 1`, 오른쪽 자식은 `2 * i + 2`이다.

해당 이진 트리에 대하여 전위 순회, 중위 순회, 후위 순회 결과를 반환하는 `solution` 함수를 구현하라. 각 순회 결과는 방문한 노드 값을 순서대로 이어 붙인 문자열이며, `[전위, 중위, 후위]` 순으로 반환한다.

- 전위 순회: 루트 → 왼쪽 서브트리 → 오른쪽 서브트리
- 중위 순회: 왼쪽 서브트리 → 루트 → 오른쪽 서브트리
- 후위 순회: 왼쪽 서브트리 → 오른쪽 서브트리 → 루트

## 제한 조건

- `1 <= nodes의 길이 <= 1,000`
- `nodes`의 원소는 정수이며 중복되지 않는다.
- `nodes[i] >= 0`

## 입출력 예

| nodes | result |
| --- | --- |
| `[1, 2, 3, 4, 5, 6, 7]` | `["1245367", "4251637", "4526731"]` |

## 입출력 예 설명

### 입출력 예 #1

문제의 트리와 같다.

- 전위: `1 → 2 → 4 → 5 → 3 → 6 → 7` → `"1245367"`
- 중위: `4 → 2 → 5 → 1 → 6 → 3 → 7` → `"4251637"`
- 후위: `4 → 5 → 2 → 6 → 7 → 3 → 1` → `"4526731"`
