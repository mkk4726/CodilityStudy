# 할인 행사

## 문제 설명

XYZ 마트는 일정한 금액을 지불하면 10일 동안 회원 자격을 부여한다. 회원에게는 매일 한 가지 제품을 할인하며, 할인 제품은 하루에 하나씩만 구매할 수 있다.

정현이는 원하는 제품과 수량이 할인하는 날짜와 10일 연속으로 일치할 때 회원가입을 하려고 한다.

예를 들어 원하는 제품이 바나나 3개, 사과 2개, 쌀 2개, 돼지고기 2개, 냄비 1개이고, 14일간 할인 제품이 날짜 순서대로 치킨, 사과, 사과, 바나나, 쌀, 사과, 돼지고기, 바나나, 돼지고기, 쌀, 냄비, 바나나, 사과, 바나나인 경우를 보자.

- 첫째 날부터 열흘에는 냄비가 할인되지 않으므로 가입하지 않는다.
- 둘째 날부터 열흘에는 바나나를 원하는 만큼 살 수 없으므로 가입하지 않는다.
- 셋째 날, 넷째 날, 다섯째 날부터 각각 열흘은 원하는 제품과 수량이 일치하므로, 이 중 하루에 가입하면 된다.

원하는 제품을 나타내는 문자열 배열 `want`, 원하는 수량을 나타내는 정수 배열 `number`, 할인 제품을 나타내는 문자열 배열 `discount`가 주어질 때, 원하는 제품을 모두 할인받을 수 있는 회원등록 날짜의 총 일수를 반환하는 `solution` 함수를 구현하라. 가능한 날이 없으면 `0`을 반환한다.

## 제한 조건

- `1 <= want의 길이 = number의 길이 <= 10`
- `1 <= number의 원소 <= 10`
- `number[i]`는 `want[i]`의 수량을 의미하며, `number`의 원소의 합은 10이다.
- `10 <= discount의 길이 <= 100,000`
- `want`와 `discount`의 원소는 알파벳 소문자로 이루어진 문자열이다.
- `1 <= want의 원소의 길이, discount의 원소의 길이 <= 12`

## 입출력 예

| want | number | discount | result |
| --- | --- | --- | --- |
| `["banana", "apple", "rice", "pork", "pot"]` | `[3, 2, 2, 2, 1]` | `["chicken", "apple", "apple", "banana", "rice", "apple", "pork", "banana", "pork", "rice", "pot", "banana", "apple", "banana"]` | `3` |
| `["apple"]` | `[10]` | `["banana", "banana", "banana", "banana", "banana", "banana", "banana", "banana", "banana", "banana"]` | `0` |

## 입출력 예 설명

### 입출력 예 #1

문제의 예시와 같다. 셋째 날, 넷째 날, 다섯째 날부터 각각 열흘이 원하는 제품과 수량과 일치하므로 `3`을 반환한다.

### 입출력 예 #2

사과가 할인하는 날이 없으므로 `0`을 반환한다.
