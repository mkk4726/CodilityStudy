# 메뉴 리뉴얼

## 문제 설명

단품으로만 제공하던 메뉴를 조합해 코스요리로 재구성한다. 각 손님이 주문할 때 가장 많이 함께 주문한 단품메뉴 조합을 코스요리 후보로 만든다.

- 코스요리는 최소 2가지 이상의 단품메뉴로 구성한다.
- 최소 2명 이상의 손님으로부터 주문된 조합만 후보에 포함한다.

예를 들어 손님 6명의 주문이 다음과 같다면,

| 손님 번호 | 주문한 단품메뉴 조합 |
| --- | --- |
| 1번 | A, B, C, F, G |
| 2번 | A, C |
| 3번 | C, D, E |
| 4번 | A, C, D, E |
| 5번 | B, C, F, G |
| 6번 | A, C, D, E, H |

가장 많이 함께 주문된 조합에 따라 코스요리 후보는 다음과 같다.

| 코스 종류 | 메뉴 구성 | 설명 |
| --- | --- | --- |
| 요리 2개 코스 | A, C | 1, 2, 4, 6번 손님으로부터 4번 주문 |
| 요리 3개 코스 | C, D, E | 3, 4, 6번 손님으로부터 3번 주문 |
| 요리 4개 코스 | B, C, F, G | 1, 5번 손님으로부터 2번 주문 |
| 요리 4개 코스 | A, C, D, E | 4, 6번 손님으로부터 2번 주문 |

각 손님이 주문한 단품메뉴가 담긴 배열 `orders`, 추가하고 싶은 코스요리의 단품 개수가 담긴 배열 `course`가 주어질 때, 새로 추가할 코스요리 구성을 문자열 배열로 반환하는 `solution` 함수를 구현하라.

정답은 사전 순으로 오름차순 정렬한다. 각 문자열도 알파벳 오름차순으로 정렬한다. 가장 많이 주문된 구성이 여러 개면 모두 담는다.

## 제한 조건

- `orders` 배열의 크기는 2 이상 20 이하이다.
- `orders`의 각 원소는 크기가 2 이상 10 이하인 문자열이다.
- 각 문자열은 알파벳 대문자로만 이루어져 있고, 같은 알파벳이 중복되지 않는다.
- `course` 배열의 크기는 1 이상 10 이하이다.
- `course`의 각 원소는 2 이상 10 이하인 자연수이며 오름차순으로 정렬되어 있다.
- `course`에는 같은 값이 중복되지 않는다.
- `orders`와 `course`는 반환 배열의 길이가 1 이상이 되도록 주어진다.

## 입출력 예

| orders | course | result |
| --- | --- | --- |
| `["ABCFG", "AC", "CDE", "ACDE", "BCFG", "ACDEH"]` | `[2, 3, 4]` | `["AC", "ACDE", "BCFG", "CDE"]` |
| `["ABCDE", "AB", "CD", "ADE", "XYZ", "XYZ", "ACD"]` | `[2, 3, 5]` | `["ACD", "AD", "ADE", "CD", "XYZ"]` |
| `["XYZ", "XWY", "WXA"]` | `[2, 3, 4]` | `["WX", "XY"]` |

## 입출력 예 설명

### 입출력 예 #1

문제의 예시와 같다.

### 입출력 예 #2

`AD`가 세 번, `CD`가 세 번, `ACD`가 두 번, `ADE`가 두 번, `XYZ`가 두 번 주문됐다. 요리 5개를 주문한 손님은 1명뿐이므로, 최소 2명 조건에 의해 5개 코스는 추가하지 않는다.

### 입출력 예 #3

`WX`가 두 번, `XY`가 두 번 주문됐다. 3개 구성은 2명 이상에게서 나오지 않았고, 4개 이상을 주문한 손님도 없으므로 해당 코스는 추가하지 않는다.
