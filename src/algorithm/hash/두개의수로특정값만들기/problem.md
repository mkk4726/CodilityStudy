# 두 개의 수로 특정 값 만들기

## 문제 설명

양의 정수로 이루어진 리스트 `arr`와 정수 `target`이 주어진다. `arr`에서 서로 다른 두 수의 합이 `target`인 쌍이 있으면 `True`, 없으면 `False`를 반환하는 `solution` 함수를 구현하라.

## 제한 조건

- `arr`의 길이는 1 이상 1,000 이하이다.
- `arr`의 각 원소는 1 이상 10,000 이하의 자연수이다.
- `arr`의 원소는 중복되지 않는다.
- `target`은 1 이상 20,000 이하의 자연수이다.

## 입출력 예

| arr | target | return |
| --- | --- | --- |
| `[1, 2, 3, 4, 8]` | `6` | `true` |
| `[2, 3, 5, 9]` | `10` | `false` |

## 입출력 예 설명

### 입출력 예 #1

`2`와 `4`의 합이 `6`이므로 `true`.

### 입출력 예 #2

서로 다른 두 수의 합이 `10`이 되는 쌍이 없으므로 `false`. (`5 + 5`는 같은 원소를 두 번 쓰는 것이므로 허용되지 않는다.)
